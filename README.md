# Free Font Manifesto

An editorial web piece setting Ellen Lupton's "Free Font Manifesto", designed by Jennie Kwon (2026).

Live: https://jkwon20241.github.io/freefontmanifesto/

- Desktop: sticky contents sidebar. Mobile: index menu.
- The outlined glyph fields on the cover and back cover ink as you scroll; click or tap a letter to press it red.
- Display type and the commercial specimens (GT America, Untitled Serif, Söhne Mono, GT Walsheim) are drawn as outlines; running text is Hanken Grotesk. Open-source specimens use Inter, EB Garamond, JetBrains Mono and Poppins from Google Fonts.
- `tools/` holds the generator scripts (they need the fonts installed locally).
